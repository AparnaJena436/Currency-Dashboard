# FX Plus – Currency Dashboard

An interactive currency dashboard that uses live exchange-rate data to provide currency conversion and exchange-rate tracking.

## Features :

* Multi-currency conversion
* Live exchange-rate data
* Currency watchlist
* Exchange-rate visualization
* Simple, interactive interface

## Built With

HTML • CSS • JavaScript • ExchangeRate-API

## Data Source

Exchange-rate data is retrieved using ExchangeRate-API.
